# Лабораторна робота №2: Наука про дані (підготовчий етап)

## Опис завдання
Ця лабораторна робота складається з двох частин:
1. **Частина 1:** Завантаження, очищення (data cleaning) та аналіз VHI-індексу для адміністративних одиниць України за допомогою `urllib` та `pandas`.
2. **Частина 2:** Аналіз датасету *Individual Household Electric Power Consumption* за допомогою `pandas`, обчислення статистичних показників (Пірсон, Спірмен), One Hot Encoding та профілювання часу виконання процедур модулем `timeit`.

---

## Вимоги до системи та інтерпретатора
* **Операційна система:** Windows / macOS / Linux
* **Версія Python:** 3.8 або вище (рекомендовано 3.10+)

---

## Інструкція із запуску

**1. Створення та активація віртуального середовища:**
```bash
python -m venv venv

# Для Windows:
venv\Scripts\activate

# Для Mac/Linux:
source venv/bin/activate
```
**2. Встановлення залежностей:**
```bash
pip install -r requirements.txt
```
**3. Підготовка даних:**
Усі необхідні датасети (для обох частин лабораторної роботи) завантажуються та розпаковуються скриптами автоматично під час виконання перших комірок у Jupyter Notebook. Нічого завантажувати вручну не потрібно.

**4. Запуск проєктів:**
```bash
jupyter notebook
```
Після запуску відкрийте файли Lab2_1.ipynb та Lab2_2.ipynb у браузері та виконайте комірки послідовно.
