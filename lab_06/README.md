# Лабораторна робота №6: C++ openCV

---

## Опис завдання
Ця програма демонструє роботу з потоковим відео з веб-камери в реальному часі за допомогою бібліотеки OpenCV у середовищі Linux. 

Проєкт має модульну архітектуру (кожен клас винесено в окремі файли) та підтримує інтерактивну обробку кадрів. Програма зчитує відео, реагує на натискання клавіатури та миші, а також застосовує візуальні ефекти залежно від обраного режиму.

---

## Функціонал та керування
Під час роботи програми ви можете перемикати режими обробки та взаємодіяти з відеорядом.

**Режими обробки (клавіатура):**
* `1` — **Normal** (Оригінальне зображення без ефектів).
* `2` — **Glitch Effect** (Зсув RGB каналів).
* `3` — **Sobel Vision** (Виділення контурів, ефект "кібер-зору").
* `4` — **Pixelate** (Пікселізація зображення).
* `q` або `ESC` — Завершення роботи програми та закриття камери.

**Інтерактивні елементи:**
* **Слайдер "Intensity":** Керує силою обраного ефекту (наприклад, розміром пікселя або інтенсивністю зсуву каналів). Знаходиться у вікні трансляції.
* **Миша:** Затисніть ліву кнопку миші (ЛКМ) на відео, щоб намалювати динамічний приціл за координатами курсора.

---

## Короткий опис архітектури
Проєкт побудовано за принципами об'єктно-орієнтованого програмування:
* `CameraProvider` — клас, що відповідає за взаємодію з драйвером веб-камери та оптимізоване захоплення кадрів у форматі MJPG.
* `KeyProcessor` — обробляє натискання клавіш та відповідає за зміну станів програми.
* `Display` — візуалізує фінальний кадр, обробляє повзунок та події миші.
* `FrameProcessor` — ядро візуальної обробки: застосовує обрані матричні фільтри до поточного кадру та малює UI-елементи.

---

## Вимоги до системи та заліза
* **Операційна система:** Linux (протестовано на Ubuntu/Debian).
* **Апаратне забезпечення:**
  * Процесор: 1.7 GHz або швидший.
  * Оперативна пам'ять: від 1 GB.
  * Наявність підключеної веб-камери (пристрій `/dev/video0` або аналогічний).
* **Компілятор:** GCC/G++ із підтримкою стандарту C++17.
* **Утиліти та бібліотеки:** CMake (3.10+), Make, OpenCV 4.x (`libopencv-dev`).

## Інструкція для білду і запуску

Проєкт містить автоматизовані bash-скрипти для швидкого розгортання на чистій системі. Відкрийте термінал у кореневій директорії проєкту та виконайте наступні кроки.

**1.Відкрийте термінал та клонуйте репозиторій. Після цього перейдіть в робочу директорію:**
```bash
git clone https://github.com/Webs1337/Data_Science_Labs
cd Data_Science_Labs/lab_06/
```
**2. Надайте права на виконання скриптам:**
```bash
chmod +x preinstall.sh build.sh run.sh
```
**3. Встановіть необхідні залежності:**
Скрипт автоматично встановить CMake, компілятори та бібліотеку OpenCV (потребує прав адміністратора).
```bash
./preinstall.sh
```
**4. Скомпілюйте проєкт:**
Скрипт створить директорію build, налаштує CMake та збере виконуваний файл.
```bash
./build.sh
```
**5. Запустіть програму:**
(Може знадобитися запуск через sudo, якщо ваша система вимагає прав root для доступу до веб-камери /dev/video0).
```bash
./run.sh
```
