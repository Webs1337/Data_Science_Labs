# Лабораторна робота №4: Візуалізація даних 2
---

## Опис завдання
Ця лабораторна робота присвячена створенню програми з графічним інтерфейсом (GUI) для інтерактивної візуалізації функції гармоніки $y(t) = A \cdot \sin(\omega t + \phi)$ з накладеним нормально розподіленим шумом. 
Реалізовано можливість у реальному часі змінювати параметри амплітуди, частоти, фази, а також середнього значення та дисперсії шуму за допомогою інтерактивних слайдерів. Для очищення зашумленого сигналу застосовується низькочастотний IIR фільтр Баттерворта (`scipy.signal.filtfilt`), який ефективно згладжує шум без створення фазового зсуву.

---

## Вимоги до системи та інтерпретатора
* **Операційна система:** Windows / macOS / Linux
* **Версія Python:** 3.8 або вище (рекомендовано 3.10+)

---

## Інструкція із запуску

**1. Створення та активація віртуального середовища:**

Для Windows (cmd):
```bash
python -m venv venv
venv\Scripts\activate.bat
```
Для Mac/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```
**2. Встановлення залежностей:**

```bash
pip install -r requirements.txt
```
**3. Запуск програми:**

Відкрийте файл `Lab4.ipynb` у Jupyter Notebook або JupyterLab та виконайте всі комірки. Графік відкриється в окремому інтерактивному вікні завдяки команді `%matplotlib tk`.

**4. Використання програми:**

Після запуску відкриється окреме вікно matplotlib.

Нижні повзунки (слайдери) дозволяють керувати параметрами чистої гармоніки, накладеного шуму та частотою зрізу фільтра в реальному часі. Зверніть увагу: шум не генерується наново при зміні параметрів чистої гармоніки.

Чекбокси праворуч вмикають та вимикають відображення еталонної (чистої), зашумленої та відфільтрованої ліній.

Кнопка "Reset" відновлює всі параметри до початкових значень.
