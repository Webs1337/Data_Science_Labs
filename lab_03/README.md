# Лабораторна робота №3: Візуалізація даних

## Опис завдання
Ця лабораторна робота присвячена розвідувальному аналізу та багатовимірній візуалізації даних:
1. **Data Cleaning:** Завантаження унікального датасету *Auto MPG* (з репозиторію UCI), обробка пропущених значень (Missing Values) та підготовка різнотипних атрибутів (Categorical, Integer, Real).
2. **Візуалізація даних:** Побудова набору графіків за допомогою `matplotlib` та `seaborn`. Включає базові залежності (scatter plot), гістограму на 5 діапазонів, багатовимірні візуалізації (3D на площині, 4D Bubble Chart, Violin Plot) та матрицю кореляції (Heatmap) згідно з вимогами та наведеними статтями.

---

## Вимоги до системи та інтерпретатора
* **Операційна система:** Windows / macOS / Linux
* **Версія Python:** 3.8 або вище (рекомендовано 3.10+)

---

## Інструкція із запуску

**1. Створення та активація віртуального середовища:**
```bash
python -m venv venv

# Для Windows:
venv\Scripts\activate

# Для Mac/Linux:
source venv/bin/activate
```
**2. Встановлення залежностей:**

```bash
pip install -r requirements.txt
```
**3. Підготовка даних:**
Датасет Auto MPG завантажується безпосередньо в пам'ять програми з офіційного джерела UCI (за допомогою pandas) під час виконання комірки очищення даних. Жодних архівів чи датасетів завантажувати вручну не потрібно.

**4. Запуск проєктів:**

```bash
jupyter notebook
```
Після запуску відкрийте файл Lab3.ipynb у браузері та виконайте комірки послідовно.
