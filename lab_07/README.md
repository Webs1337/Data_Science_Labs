# Лабораторна робота №7: Computer Vision та багатопотоковість у C++

---

## Опис завдання
Проєкт є розвитком попередньої лабораторної роботи. Основна мета — поєднання класичної обробки відео з сучасними методами Computer Vision та Machine Learning, а саме: інтеграція детектора облич на базі архітектури **ResNet-10 SSD** через модуль `cv::dnn`.

Для вирішення проблеми падіння FPS через "важкі" обчислення нейромережі, інференс моделі було винесено в окремий фоновий потік. Завдяки використанню багатопотоковості (`std::thread`) та примітивів синхронізації (`std::mutex`, `std::atomic`), основний відеопотік залишається ідеально плавним, а координати облич оновлюються асинхронно.

---

## Функціонал та керування
Програма підтримує перемикання між візуальними ефектами та ML-детекцією "на льоту".

**Режими обробки (клавіатура):**
* `1` — **Normal** (Оригінальне зображення без ефектів).
* `2` — **Glitch Effect** (Зсув RGB каналів).
* `3` — **Sobel Vision** (Виділення контурів, ефект "кібер-зору").
* `4` — **Pixelate** (Пікселізація зображення).
* `F` — **Face Detection** (Асинхронний пошук облич через нейромережу).
* `Q` або `ESC` — Завершення роботи програми.

**Інтерактивні елементи:**
* **Слайдер "Intensity":** Керує силою обраного візуального ефекту.
* **Миша:** Затисніть ліву кнопку миші (ЛКМ) на відео, щоб намалювати динамічний приціл.

## Архітектура та Багатопотоковість

Проєкт побудовано за принципами ООП. Головне нововведення рівня 2 — клас `FaceDetector`.

* **`FaceDetector` (Фоновий потік):** Відповідає за асинхронну детекцію. 
  * Містить `std::thread workerThread`, який працює у фоні та виконує `net.forward()` щойно з'являється новий кадр.
  * Використовує `std::mutex mtx` для безпечного копіювання кадру з головного потоку та безпечної передачі знайдених координат (`std::vector<cv::Rect>`) назад у головний потік.
  * Використовує `std::atomic<bool> running` для безпечного завершення життєвого циклу потоку.
* **`FrameProcessor`:** Ядро візуальної обробки. Застосовує матричні фільтри та малює зелені рамки навколо облич (метод `drawFaces`).
* **`CameraProvider`, `Display`, `KeyProcessor`:** Модулі для роботи з V4L2 камерою, відображенням UI та перехопленням подій.

Головний потік (`main`) **не чекає** завершення роботи нейромережі. Він просто відправляє копію кадру під м'ютексом і забирає останні відомі координати, що гарантує відсутність фризів відео.

## Модель нейромережі
Використовується офіційна модель детекції облич OpenCV (ResNet-10 SSD).
* **Архітектура:** [deploy.prototxt](https://raw.githubusercontent.com/opencv/opencv/master/samples/dnn/face_detector/deploy.prototxt)
* **Ваги:** [res10_300x300_ssd_iter_140000.caffemodel](https://raw.githubusercontent.com/opencv/opencv_3rdparty/dnn_samples_face_detector_20170830/res10_300x300_ssd_iter_140000.caffemodel)
* **Вхідні дані:** Кадр перетворюється у `blob` розміром 300x300 з mean subtraction `(104.0, 177.0, 123.0)`. Поріг впевненості (Confidence) встановлено на рівні 50%.

## Вимоги до системи
* **ОС:** Linux (протестовано на Ubuntu/Debian).
* **Компілятор:** GCC/G++ із підтримкою стандарту C++17.
* **Утиліти та бібліотеки:** CMake (3.10+), Make, OpenCV 4.x (`libopencv-dev`), `wget`.
* **Апаратне забезпечення:** Наявність веб-камери (`/dev/video0`).

## Інструкція зі збірки та запуску

Проєкт містить автоматизовані bash-скрипти. Відкрийте термінал у кореневій директорії проєкту та виконайте наступні кроки.

**1. Клонуйте репозиторій та перейдіть в директорію лаби:**
```bash
git clone https://github.com/Webs1337/Data_Science_Labs.git
cd Data_Science_Labs/lab_07/
```
**2. Надайте права скриптам:**
```bash
chmod +x preinstall.sh build.sh run.sh
```
**3. Встановіть залежності та завантажте модель:**
(Скрипт встановить OpenCV, CMake та завантажить ваги нейромережі за допомогою wget)
```bash
./preinstall.sh
```
**4. Скомпілюйте проєкт:**
```bash
./build.sh
```
5. Запустіть програму:
```bash
./run.sh
```
