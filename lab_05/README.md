# Лабораторна робота №5: Наука про дані: обмін результатами та початковий аналіз
---

## Опис завдання
Ця лабораторна робота присвячена створенню інтерактивного вебдодатка на базі фреймворку `Streamlit` для візуалізації та аналізу агрокліматичних показників (VCI, TCI, VHI) України. 

Реалізовано систему автоматичного завантаження даних із серверів NOAA, що дозволяє програмі працювати автономно без необхідності зберігання масивних датасетів у репозиторії. Додаток дозволяє у реальному часі фільтрувати дані за областю, типом індексу та часовим інтервалом. Результати аналізу представлені у вигляді динамічних графіків та порівняльних рейтингів областей з використанням бібліотеки `Plotly`.

---

## Вимоги до системи та інтерпретатора
* **Операційна система:** Windows / macOS / Linux
* **Версія Python:** 3.8 або вище (рекомендовано 3.10+)
* **Інтернет-з'єднання:** Необхідне для першого запуску (автоматичне стягування даних)

---

## Інструкція із запуску

**1. Створення та активація віртуального середовища:**

Для Windows:
```bash
python -m venv venv
venv\Scripts\activate.bat
```
Для Mac/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```
**2. Встановлення залежностей:**
```bash
pip install -r requirements.txt
```
**3. Запуск програми:**

Вебдодаток запускається командою:
```bash
streamlit run lab5.py
```
Після виконання команди у вашому браузері автоматично відкриється вкладка з інтерфейсом програми.  

(за замовчуванням http://localhost:8501)

**4. Використання програми:**

При першому запуску програма ініціалізує базу даних, завантажуючи актуальні файли з NOAA (ви побачите індикатор прогресу).

Панель налаштувань у лівій колонці дозволяє:
* Обирати тип індексу (VCI, TCI, VHI) та конкретну область України.
* Регулювати діапазони тижнів та років за допомогою слайдерів.
* Керувати сортуванням даних у таблиці за допомогою чекбоксів (реалізовано захист від конфлікту параметрів).

Основна частина екрана містить три вкладки:
* **Зведена таблиця:** відображає відфільтровані текстові дані.
* **Тренд індексу:** показує зміну обраного показника в часі для вибраної області.
* **Регіональний рейтинг:** порівнює середнє значення індексу по всіх областях України (обрана область підсвічується окремим кольором).

Кнопка "Відновити за замовчуванням" миттєво повертає всі фільтри до початкових значень.
